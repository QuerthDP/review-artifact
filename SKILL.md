# /review-artifact <PR> [--stop]

Argument: a PR URL or `owner/repo#N` (or `N` in the current repo). `$R` is this skill's directory. Run it inside a local clone of the PR's repository. This session only starts the app and its agent; it never answers the page itself.

1. Start the app: `python3 -I $R/local/server.py <PR> --open --detach` (foreground, Bash timeout 600000). It fetches the PR, builds the page data, starts the server in the background (it outlives this session), opens the page in a browser tab and prints one JSON line: `url`, `port`, `state` (`$ST`), `login`, `fork`, `mine`, and `reused: true` when a server for this PR was already running (it then only opens a tab). Options: `--repo-dir`, `--port` (default: the first free one from 8765), `--no-push` (accepts stay on the local review branch). If it fails, show the user the error and the end of `$ST/server.log`.
2. Unless it was `reused` and an agent from this session is still answering it, spawn the answering agent: one `Agent` call, `subagent_type: "general-purpose"` (it runs in the background), description `review agent <owner/repo>#<N>`, prompt: `You are the local review agent for <owner/repo>#<N>. Read <$R>/local/agent.md and follow it exactly. R=<$R> ST=<state> P=<port>. PR repo dir: <cwd>. The user's login: <login>; the PR is the user's own: <mine>.` Give it `model: "sonnet"`: it only polls and does the mechanical work, spawning Opus for anything that needs judgement (`workflow.md` §4, **Models**). Pass the user's explicit model or effort choice instead, if any; otherwise leave effort out.
3. Tell the user, in one or two lines: the url, and that a background agent answers the page.
4. When the agent's completion notification arrives: on `IDLE`, wait for the next request: `python3 -I $R/local/store.py --port <port> wait` with `run_in_background: true`, and say nothing. When that finishes with `pending <n>`, spawn a fresh agent with the same prompt and say nothing; with `server stopped`, tell the user in one line; if it ends any other way, start it again. On `HANDOFF`, spawn a fresh agent with the same prompt and say nothing else; on `DONE <reason>`, tell the user in one line; on anything else (an error, a crash), spawn it again once and tell the user in one line. Never relay the agent's work otherwise. Only one agent or one wait runs at a time.

`--stop`: run `python3 -I $R/local/server.py <PR> --stop` and stop this session's agent for that PR (`TaskStop`), if any.

The server stops itself once the PR is closed. Nothing is ever pushed to the upstream repository: accepted changes go to `review/pr-<N>` on the user's fork, and onto the PR branch only after "Push to the PR", and only when that branch is on the fork.
